## 🛠️ Tecnologias

### Frontend
- **React 18** - Uma biblioteca JavaScript para construir interfaces de usuário interativas
- **TypeScript** - Superset do JavaScript com tipagem estática para código mais seguro e mantível
- **Tailwind CSS** - Framework CSS utilitário para estilização rápida e responsiva
- **Vite** - Build tool moderno e extremamente rápido para desenvolvimento
- **React Router DOM** - Roteamento client-side para navegação entre páginas

### Deploy
- **GitHub Pages** - Hospedagem gratuita e integrada com GitHub
